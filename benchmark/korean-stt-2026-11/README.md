## 요약

- `microsoft/mai-transcribe-2`가 삽입을 뺀 CER 4.6%로 가장 낮았다. 유효 18개 구간 중 16개에서 핵심 5개 설정 중 1위였고, 2위 Scribe와의 대응 차이는 2.0%포인트(95% CI 1.4~2.7)다.
- 속도와 비용도 앞섰다. 응답 시간 중앙값 3.7초, 오디오 1시간당 $0.10이다.
- 삽입까지 포함한 CER로는 MAI, Scribe, Gemini, GPT의 차이가 작다(12.5~13.3%). MAI와 Gemini, MAI와 GPT의 대응 차이는 신뢰구간이 0을 포함한다. 자막이 추임새를 지우는 탓에 삽입 수치가 부풀어(추정) 이 지표만으로 순위를 매기지 않았다.
- 야외처럼 말이 겹치고 시끄러운 음성에서 차이가 벌어진다. 합의 내용 누락률이 MAI 6.8%, Scribe 6.7%, Gemini 17.0%, GPT 23.0%, Nemotron 25.0%다.
- 거의 안 들리는 합성 음성에서 MAI와 Scribe는 없는 문장을 지어냈다. 다른 모델은 짧게 내놓거나 비워 냈다. 이런 음성에서 글자 수가 많은 쪽이 좋은 결과는 아니다.

여기 수치는 유튜브 표본의 결과다. 실제로 쓸 녹음에서 다시 확인해야 한다.

## 데이터

아나운서 음성을 피하고 일반 유튜버 영상 위주로 골랐다. 사람이 직접 단 한국어 자막이 있는 영상만 후보로 삼았다. 전체 목록은 [`data/clips.csv`](data/clips.csv)에 있다.

| 범주 | 구간 수 | 채널 |
| --- | --- | --- |
| `english` 영어 용어가 섞인 설명 | 4 | 코딩애플, underKG, 잔재미코딩, 빠더너스 |
| `single` 혼자 말하기 | 3 | 잇섭, 판교 뚜벅쵸, 귤치 |
| `talk` 여러 명의 대화 | 3 | 입만열면, 챌린지 가이즈, 침착맨 |
| `outdoor` 야외 | 6 | 인영인영, 치킨보이, MrNoul, 엉클존스캐빈, 유튜브하지영, 엄지 |
| `meeting` 회의실과 강연장 | 5 | 기업강사나비쌤, JazzyMind, Idol Backstage, 국민TV(2) |

- **구간 선택.** 영상 길이의 20% 지점 뒤 첫 자막에서 시작해 300초 안에 끝나는 마지막 자막까지 쓴다. 330초 이하 영상은 처음부터 쓴다. 규칙은 [`scripts/window.py`](scripts/window.py)에 있다.
- **입력 형식.** 16 kHz 모노 64 kbps MP3. ffmpeg 9.0.2.
- **신호 대 잡음 추정.** 30 ms 프레임 레벨의 P90과 P10 차이로 계산했다. 실제 구간은 17.1~49.6 dB, 합성 음성은 5.5~13 dB다. 측정된 SNR이 아니라 상대 비교용 추정치다.

합성 음성은 기준 구간 2개(`QndOyQtTHUQ`, `MHI2bTsLj90`)에 두 조건을 입혔다. 처리는 [`scripts/synth.sh`](scripts/synth.sh)에 있다.

- **`crowd5db`.** 다른 구간 6개를 거꾸로 돌려 섞은 군중 소리를 약 5 dB 신호 대 잡음비로 더한다.
- **`farmic`.** 메아리, 200~3400 Hz 대역 제한, -20 dB 감쇠, 분홍 잡음으로 먼 마이크를 흉내 낸다.

## 지표

정규화는 NFKC, 소문자화 후 `[가-힣a-z0-9]`만 남긴다. 띄어쓰기와 문장부호는 채점하지 않는다.

| 지표 | 정의 | 읽는 법 |
| --- | --- | --- |
| CER | (치환+삭제+삽입) / 자막 글자 수 | 자막이 받아쓰기에 가까울 때만 믿을 수 있다. |
| 삽입 제외 CER | (치환+삭제) / 자막 글자 수 | 이 보고서의 주 지표다. 추임새를 많이 받아쓰는 모델이 불리하지 않다. 대신 지어낸 내용을 벌하지 않는다. |
| 합의 누락률 | 핵심 5개 설정 중 3개 이상이 낸 4글자 조각 가운데 빠뜨린 비율 | 자막 없이 계산하는 보조 지표다. 다수와 같은 실수는 드러나지 않는다. |
| 정밀도, 재현율(합성) | 일치 글자 수 / 출력 글자 수, 일치 글자 수 / 자막 글자 수 | 지어낸 내용과 빠뜨린 내용을 나눠 본다. |
| 응답 시간 | 요청부터 응답까지의 벽시계 시간 | 실제 음성은 동시 5건, 합성은 동시 4건으로 보냈다. |

핵심 5개 설정은 `gpt-ko`, `scribe-ko`, `gemini-koen`, `mai-ko`, `nemo-ko`다. 합의 집합에 들어가지 않는 `gpt-koen`과 `nemo-prompt`는 자기 출력이 투표에 없어 누락률이 약간 불리하다.

**제외한 구간.** 핵심 5개 설정 모두 CER이 50%를 넘은 3개(`MWEBO7idPhQ`, `I3udwVGVjms`, `JEMS-Cn5960`)는 자막이 받아쓰기가 아니라고 보고 CER 계산에서 뺐다. 이 규칙은 결과를 본 뒤에 정했다. 합의 누락률은 자막을 쓰지 않으므로 21개 전부로 계산했다. 규칙을 빼고 21개로 계산해도 삽입 제외 CER 순서는 MAI, Scribe, Gemini, GPT `ko`, GPT `ko,en`, Nemotron 프롬프트, Nemotron이고, 값은 7.7~15.4%다.

신뢰구간은 구간 단위 대응 부트스트랩이다(1만 회, 고정 시드, 95% 백분위). 같은 표는 `scripts/summarize.py`가 공개 CSV에서 다시 계산한다.

## 관찰한 실패

- **Gemini 빈 응답.** 먼 마이크 음성 2개에서 HTTP 200과 빈 글을 돌려줬고 입력 토큰 비용이 청구됐다. 상태 코드만으로는 실패를 잡을 수 없다.
- **Gemini 조기 종료.** `JEMS-Cn5960`에서 358자를 냈다. 다른 모델은 약 1090자였다. 다시 돌려도 387자, 222자였다.
- **GPT 조기 종료.** `I3udwVGVjms`에서 665자를 냈다. 다른 모델은 1345~1571자였고 다시 돌려도 659자였다. 180초로 나눠 보내자 합의 누락률이 55.6%에서 25.1%로 줄었다. 함께 시험한 다른 7개 구간에서는 나눠 보내도 차이가 작았다.
- **MAI 지어내기.** `MHI2bTsLj90_farmic`에서 음성에 없는 자기소개를 소속과 이름까지 붙여 만들어 냈다.
- **Scribe 지어내기.** `MHI2bTsLj90_crowd5db`에서 음성에 없는 직장 이야기 문장들을 넣어 자막의 두 배 가까운 글을 냈다.

## 비용

`usage.cost` 합계다. Gemini는 오디오 초를 돌려주지 않아 구간 길이로 나눴다. 유튜브 구간 합은 1.739시간이고, MAI가 돌려준 `usage.seconds` 합은 1.768시간이다.

`gpt-transcribe`는 `usage.cost`가 0이었지만 무료라고 볼 수 없다. 첫 배치의 잔액 감소는 다른 모델 비용 합과 일치했으나($1.598), GPT만 보낸 재현 시험 중에는 잔액이 $0.4276 줄었다. 실제 청구는 확인하지 못했다.

## 한계

- 사람이 음성을 직접 듣고 채점하지 않았다. 정답 대신 사람이 단 자막을 썼고, 자막은 추임새를 지우거나 편집 문구를 넣기도 한다.
- 설정과 구간 조합마다 1회만 돌렸다. 같은 입력의 변동은 조기 종료 사례에서만 확인했다.
- 유효 18개 구간은 작은 표본이다. 같은 채널이 2번 들어간 곳도 있어 구간 독립 가정은 근사다.
- 3개 구간 제외 규칙은 결과를 본 뒤 정했다. 민감도 결과를 위에 함께 적었다.
- 응답 시간은 OpenRouter와 제공사 상태, 동시 요청 수의 영향을 받는다. 모델 자체의 처리 속도로 읽으면 안 된다.
- 화자 분리, 시간 표시, 스트리밍 지연은 측정하지 않았다.
- Soniox와 `sommers`는 OpenRouter에 없어 시험하지 못했다.
- 측정에 쓴 yt-dlp 버전은 기록하지 않았다(`uvx`로 실행).

## 재현

`OPENROUTER_API_KEY`가 필요하고, 전체 실행에 $2 안팎이 든다. 측정 때 쓴 스크립트를 그대로 두었다. `summarize.py`만은 API 없이 바로 돌아간다.

```bash
# 공개 CSV에서 위 표를 다시 계산한다
python3 scripts/summarize.py data

# 입력을 다시 만들고 다시 측정한다
S=$PWD; mkdir work && cd work
"$S/scripts/download.sh" "$S/data/clips.csv"
python3 "$S/scripts/window.py" .                         # manifest.json, refs/
mkdir -p synth && "$S/scripts/synth.sh"
python3 "$S/scripts/stt.py" batch "$S/runs.json" audio ../results/real 2.4 5
python3 "$S/scripts/stt.py" batch "$S/runs.json" synth ../results/synth 0.8 4
python3 "$S/scripts/score2.py" . ../results/real
python3 "$S/scripts/score2.py" . ../results/synth
python3 "$S/scripts/snr.py" audio > snr_real.jsonl
mkdir -p ../data_new && python3 "$S/scripts/export_csv.py" . ../results ../data_new
python3 "$S/scripts/count_terms.py" ../results/real > ../data_new/latin_terms.csv
```

유튜브 영상은 삭제되거나 자막이 바뀔 수 있어 같은 입력을 보장하지 않는다.

음성과 자막, 모델이 받아쓴 글은 이 저장소에 없다. 이유는 [공개 범위](../README.md#공개-범위)에 적었다.
