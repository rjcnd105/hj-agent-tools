# 벤치마크

한국어 음성 받아쓰기와 한국어 OCR을 직접 측정한 기록이다. 각 폴더에 방법, 수치, 한계, 재현 절차가 함께 있다.

| 보고서 | 측정일 | 대상 | 핵심 결과 |
| --- | --- | --- | --- |
| [한국어 음성 받아쓰기](korean-stt-2026-11/README.md) | 2026-11-04 | OpenRouter의 5개 모델, 7개 설정, 유튜브 21개 구간과 합성 열화 음성 | `microsoft/mai-transcribe-2`가 대체로 가장 정확하고 빠르고 저렴했다. 거의 안 들리는 음성에서는 없는 문장을 지어냈다. |
| [한국어 OCR](korean-ocr-2026-10/README.md) | 2026-10-15 ~ 2026-10-30 | 로컬 OCR 모델과 정리용 텍스트 모델, 결제 내역 화면 | 가맹점명 인식은 PaddleOCR-VL-1.6이 83%, OvisOCR3가 60%였다. 공개 벤치마크 순위는 한국어 가맹점명에 그대로 옮겨지지 않았다. |

## 공개 범위

수치는 모두 CSV나 보고서 표로 공개하고, 모델이 출력한 글도 채점을 검증할 수 있도록 공개한다. 입력 파일은 권리와 개인정보에 따라 나눴다.

| 입력 | 공개 여부 | 이유와 대안 |
| --- | --- | --- |
| 직접 만든 합성 결제 화면 16장과 OCR에 넣은 줄 이미지 190장 | 포함 | 생성 스크립트와 정답 파일을 같이 둔다. 원본이 지워져 같은 스크립트로 다시 렌더링했다. |
| 합성 화면의 OCR 출력 | 포함 | 2026-11-04 재측정 출력이다. 10월 측정의 출력은 남아 있지 않다. |
| 실제 결제 내역 캡처 3장 | 제외 | 실제 결제 내역이다. 합산 수치만 싣는다. |
| 실제 가맹점명이 섞인 합성 화면 `bank-b` | 제외 | 합성 화면이지만 실제 카드 내역의 가맹점명과 금액이 한 건 들어 있다. |
| 유튜브 음성 21개 구간과 그 합성본 | 제외 | 제3자 저작물이다. 영상 ID와 구간, 내려받기 스크립트로 같은 입력을 다시 만들 수 있다. |
| 모델이 받아쓴 글 175건 | 포함 | 채점과 환각 판단을 검증하는 데 필요하다. 영상 발화에서 나온 글이므로 권리자가 요청하면 해당 클립을 뺀다. |
| 유튜브 자막(정답) | 제외 | 제3자 저작물이다. 내려받기 스크립트로 다시 받아 채점할 수 있다. |
